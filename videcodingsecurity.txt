Security & Backend Checklist:
* Hide all API keys in backend environment variables.
* Purge git secrets and sensitive history from the repository.
* Use public client database keys safely.
* Enable database Row-Level Security (RLS).
* Encrypt sensitive data at rest and in transit.
* Enforce strict server-side authentication.
* Lock down record access per user role.
* Block client-side field tampering on updates.
* Configure secure, HttpOnly, SameSite session cookies.
* Hash all passwords with a strong algorithm (e.g., Argon2 or bcrypt).
* Add rate limiting to login and authentication routes.
* Implement bot protection on public form submissions.
* Parameterize all database queries to eliminate SQL injection.
* Validate all user input on the server side.
* Escape all user-generated content before rendering to prevent XSS.
* Restrict file upload types, file extensions, and file sizes.
* Trim API responses to exclude unnecessary database fields.
* Add security headers (CSP, HSTS, X-Frame-Options, X-Content-Type-Options).
* Force HTTPS redirects across all routes.
* Scan and update dependencies to resolve known vulnerabilities.
